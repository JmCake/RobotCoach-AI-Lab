# V1.0 实现与验收记录

验收日期：2026-11-18。基线：新仓库 `main` 的 `50fbfb9`，分支 `codex/v1-foundation`。本地工作区采用隔离 worktree；原目录中的废弃代码删除状态未恢复、未带入本分支。未开始 V1.1 或 V2.0。

## 实际交付

共 11 页，原生 HTML/CSS/JavaScript、Canvas、iframe 与 localStorage；无运行框架和后台数据库。顶部三个章节，底部前后推进；直接打开第一章，可跳章、回退和刷新恢复。约 200ms 过渡支持 `prefers-reduced-motion`。

| 页 | 操作与反馈 | 恢复方式 |
| --- | --- | --- |
| 初代机诊断 | 双视角试跑、弯道偏离、再次观察 | 保留已完成反馈；中途离页后重新试跑 |
| 感官大发现 | 四个机器人热点，可重复查看 | 发现列表保留 |
| 传感器安装 | 拖拽或点击安装/卸下四种模块 | 配置跨页、刷新保留 |
| 升级试跑 | 运行配置，比较初代机与最近结果 | 保留最近 12 次结果；中途离页重新运行 |
| 行为克隆原理 | 示范动作与环境改变对照 | 保留环境选项与已完成解释 |
| 人工操控 | 空格/上箭头跳跃、下箭头下蹲及触屏按钮，碰撞/跨障碍反馈、重试 | 保留人工最高分；中途进度不保存 |
| AI 自主试错 | 实际 Q 表更新、奖励、失败重置、训练暂停与继续、速度选择、全部重置 | Q 表定期与暂停时保存，保留最近 150 轮 |
| 学习成果 | 读取同一 Q 表，探索率为零，禁止更新 | 同一份本地策略与历史 |
| 闭环拼装 | 拖拽、点击或键盘组装；验证顺序；行动连接回感知；循环与暂停 | 保留模块位置与已完成连线 |
| 闭环故障 | 分别关闭感知/决策/行动/反馈回路，显示中断原因及可播放视频 | 保留开关；运行中离页暂停 |
| 综合与总结 | 场景、任务、传感器、训练、反馈五项图形选择，组合结果即时变化 | 五项配置保留 |

## 真实学习结果

浏览器实录的一次早期训练：17 轮完成、1,056 次 Q 更新、297 个状态，最高 63 分；其中有 1–2 个障碍的通过记录，也有大量真实碰撞，未将其描述为训练完成或稳定成功。成果页冻结验证比较整个保存对象，策略及历史均不变化。

另通过相同生产引擎逐步运行三组从零训练，每组 100,000 次真实更新；训练前后均使用种子 9001 的同一 20 轮环境序列，关闭探索和更新，每轮最多 1,800 个物理帧。它们是算法验证数据，不自动注入用户浏览器或预置到课程里。

| 训练种子 | 实际完成轮次 | 学到的状态数 | 训练前平均跨障碍 | 训练后平均跨障碍 |
| --- | ---: | ---: | ---: | ---: |
| 17 | 535 | 649 | 0 | 18.00 |

原始逐轮分数、跨障碍数和末 10 轮奖励在 [JSON](v1-training-results.json)，复现命令：`node scripts/evaluate-learning.mjs`。这只验证基础跑酷训练确实改变决策，不推断对未见过的复杂赛道、真实传感器或机器人有效。

## 已知边界与交付状态

- 第一章沿用原版的条件式机制演示，具有预设教学因果；不是物理仿真，不能据此证明某个传感器必然使真实机器人通关。
- 行为克隆是原理教学与标明性质的动作回放，没有独立模仿学习模型；独立训练不属于 V1.0。
- Q-learning 是离散基础跑酷模型，训练表现受探索、轮数与随机障碍影响；不保证一次训练即可稳定完成。
- 保存已完成结果和必要配置，不保存每个实验运行到一半的物理帧。浏览器禁用/清理 localStorage 会影响长期恢复；主课程提供保存失败提示。
- 未验证物理手机、Safari/Firefox，亦未开展 V1.1 性能增强或 V2.0 泛化挑战。
- 本次交付为可运行分支及 PR，未自动合并 main；静态构建可预览或部署，正式发布需用户审查合并。
