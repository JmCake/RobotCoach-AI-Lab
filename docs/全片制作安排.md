# 《机器人总教练：奔跑的意义》制作安排

按定稿顺序，整堂课共用一个播放入口。表中的时间是 40 分钟课堂的组织建议，讨论与实验由教师掌握节奏。

| 段落 | 画面、声音和转场 | 学生参与与验收 |
| --- | --- | --- |
| 序幕，约 2 分钟 | 红色跑道、计时器、蓝白机器人活动手臂。机器人邀请全班做总教练，发令后直接接 V6 奔跑与失衡。 | 进入即播放，到手掌撑地才定格。 |
| 第一至三幕，约 10 分钟 | 在同一幅事故定格上查看眼睛、身体、脚底线索。转入维修舱，用原运动控制器做 40 米同条件复测。实测完赛才接 V6 成功过弯和矮栏。 | 全班讨论一次，选配装备。允许失败后只换一项；保留 IMU 仅测量与接入控制的区别。 |
| 第四、五幕，约 12 分钟 | 同一道栏分成两格，呈现看示范与自己试错。训练营使用原短道、模仿策略和 Q-learning，现场显示训练前后测试。广播打断训练场的安静，把画面交给决赛。 | 讨论学习方式、观看两种训练。如成绩没有改善，照实显示。 |
| 第六、七幕，约 13 分钟 | 选最终装备与策略，倒数后实跑六段。根据本场成绩收束，白线转入木栈道，先看九寨沟原图，再揭示 ONNX 输出。 | 赛前配置、失败复盘、选择落脚点、核对或纠正模型的判断。 |
| 第八、九幕，约 3 分钟 | 栈道上的提问接新闻播报。救援简报、暗处观察、姿态调整、停步回传、握手与撑地闪回、阳光拉远和终字幕剪成一条有声影片。 | 观看，持续到淡出。救援明确标注为未来应用设想。 |

## 美术执行

已逐张查看定稿里的 32 张图片。序幕参考体育场逆光、贴地起跑的机位；器材参考图用来确认外形和测量位置。跨栏画面保持障碍、支撑脚与运动方向在同一视线中。现实段落实拍保留栈道、水岸和近处落脚面。救援由远景交代人和废墟的尺度，再进入低照度通道；结尾把暖光留给人与机器相握的手。角色脸部、甲片配色和关键动作以现有 V6 原画为准。

## 角色与装备

近景参照 V6 维修舱原画。保持横向深色面罩、两只青蓝色眼睛、白色面甲、蓝绿护肩与小腿、深色关节。同场侧视动作继续使用 V6 原画拆分的头、躯干和四肢。摄像头位于头侧，IMU 在胸前，雷达在头顶，力觉在两只靴底。救援队另配腰间通信机。[角色与装备设定图](角色与装备设定.jpg)

维修舱、短道、训练测试与决赛都读取本班的装备选择。赛前检录允许主动改装，检录后的装备随角色进入救援。预渲染镜头按各帧的关节位置叠加相应配件。回忆里的初代机保留事故发生时的状态，跨栏闪回取自本次课堂的独立模仿试跑。

## 放映时间轴

固定片段按各自片头计时。课堂段按实际操作和同一次仿真前进，教师可以在任意镜头暂停。

| 镜头 | 时间或出点 | 动作、对白与接点 |
| --- | --- | --- |
| 起跑线 | 序幕 0–14.6 秒 | 体育场和计时器入画，推近招手的机器人。邀请全班后，发令声接 V6 跑道视角。 |
| 入弯与撑地 | 序幕 14.6–26 秒 | 连续播放 V6 入弯、侧倾、伸手。事故讨论的背景直接取本段最后一帧，学生留在原地看证据。 |
| 检修与复测 | 教师进入维修舱，试跑至真实结算 | 根据同一次实跑显示距离、姿态读数与扶正反馈。失败可调整，过线开启下一镜。 |
| 冲出弯道 | 矮栏段 0–2 秒 | 截取原 V6 成功镜头的出弯末段。本轮新增的可见装备按原 V6 关节位置跟随。 |
| 矮栏 | 矮栏段 2–23 秒 | 接侧面跟拍，跑速渐降，视线切至矮栏，切回原停姿。两句提问接训练方式分屏。 |
| 训练营与广播 | 以本班两项训练实际结束为出点 | 规则教练示范，机器人的独立模仿与 Q-learning 实跑依次发生，两者先后可选。冻结成绩展示后，广播从场内响起。 |
| 六段决赛 | 检录后倒数 3 秒，随运动时钟运行 | 一个世界、一套装备、一份比赛记录。查阅关键帧后，离场使用真实完赛或失败停点。 |
| 出场与栈道 | 栈道对白约 8 秒，然后教师组织观察 | 体育场尾帧渐隐至 V6 栈道，环境声由观众席转成流水与鸟鸣。真实照片上先落点，再识别与核对。 |
| 栈道上的问题 | 终章 0–14.7 秒 | 识别层退回同一照片，机器人说出真正的问题。画面渐暗，新闻声接救援现场。 |
| 简报 | 终章 14.7–40.5 秒 | 远景交代入口、救援队、机器人和空间方向。队员指向入口，机器人收到任务。 |
| 观察、落脚、停下 | 终章 40.5–70 秒 | 侧面向右行进，逐步接近光束与碎石。45.5、55.6、65.8 秒以注视、落脚和停步分别触发短闪回。 |
| 回传与返回 | 终章 70–88 秒 | 切接收终端，队员收到画面并发出停步指令，随后切队伍返回。 |
| 握手 | 终章 88–105 秒 | 手套与机械手相握，于 90–94.5 秒闪回同一台初代机当初撑地的手，再回到相握的手。 |
| 拉远、字幕、黑场 | 终章 105–133 秒 | 镜头从队伍拉远，主题字幕依次出现，129 秒开始淡出，最后保留黑场。 |

## 制作文件

六张新增原画、中文对白和合成脚本保存在 `production/feature`。放映资源在 `assets/feature`。合成使用 FFmpeg、OpenCV、Pillow、NumPy、SciPy 和原 V6 绘制代码。用 `ROBOTCOACH_V6_SOURCE` 可指定 V6 的 `source` 目录，用 `FFMPEG` 可指定编码器。直接运行 `python production/feature/render.py` 可重新生成三个固定影片段。正常放映只需本机 Node.js 和浏览器。
