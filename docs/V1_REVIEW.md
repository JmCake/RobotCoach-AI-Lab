# V1.0 PR #1 审查与修复

审查日期：2026-11-18。对象：`codex/v1-foundation` 的 PR #1，原提交 `a349636`。按用户要求先审核 V1.0，直接在同一 PR 修复缺陷；不合并 main，不启动 V1.1/V2.0。

## 发现并修复的问题

| 问题 | 修复前实测 | 修复与复测 |
| --- | --- | --- |
| 快速切页未保存最新 Q 更新 | 本机最初通过，但 Ubuntu/Chromium CI 检出应保留至少 5 次更新而实际为 0；在本机屏蔽 iframe 原生 `pagehide`/`visibilitychange` 后，稳定复现应保留 6 次、实际为 0 | 父页面在移除 iframe 前同步发送课程暂停事件，由实验完成保存，不再依赖原生离页通知；相同无原生事件用例修复后通过 |
| 旧手控/展示标签页覆盖较新的训练 | 同一浏览器先打开手控或展示，再在另一页训练；旧页面暂停后，已有 100 多次更新的 Q 表被写回空表。两条新增 E2E 均失败 | 只有训练模式可持久化 Q 数据；手控和冻结展示只读。暂停及离页均不能覆盖新训练，两条回归通过 |
| 按钮获得焦点后方向键失效 | 开始后聚焦“跳跃”按钮并按 ↑，机器人绿色像素顶部始终 170，没有跳起 | 方向键在操作按钮上仍交给游戏；空格保留按钮原生激活，输入框/选择框保留自身键盘行为。像素变化回归通过 |
| 断开反馈时动画提前返回感知 | 关闭反馈回路后，“行动”阶段机器人已离开行动节点向感知移动；180ms 后偏离行动节点约 86px | 行动阶段留在行动节点，只有反馈阶段允许返回感知；关闭反馈时不会出现这一移动。位置断言与故障回归通过 |
| 绘制修改仿真状态 | 无物理推进，仅调用绘制 5 次就把 `robot.frame` 从 0 改为 5 | 去除绘制中的状态写入，步态只读取物理帧；完整仿真快照在重复绘制后不变，单元回归通过 |
| 训练对比的各轮环境不独立 | 原评估只固定整条随机流的起点；前一轮消耗不同随机数会改变后续各轮，不能支撑“逐轮相同条件”的说法 | 每轮重新创建 RNG 和 Runner，双方使用独立种子 9001–9020；改变前轮随机数消耗不再影响后轮输入。重跑三组训练并更正 JSON/文档 |

新增回归用例先确认失败，再修复转为通过。快速切页问题最初只在 CI 暴露，随后补成不依赖本机浏览器原生离页通知的稳定复现，再修正移除 iframe 前的保存时序。没有以 Windows 本地通过掩盖 Linux CI 失败。
