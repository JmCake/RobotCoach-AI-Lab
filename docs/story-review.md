# 翻到下一页，故事怎样接着走

教师试玩《机器人进化跑》后说“都进行到下一页了总是回到上一页”。这里的“回退”指教学设计。学生已经看到了结果或做出了决定，下一页的提问、镜头或任务却把他带回刚才的内容。请从学生的视角审阅各页的先后关系。

学生扮演同一台机器人的总教练。第一关从一次弯道失衡开始，学生提出猜想、改装、实跑，用自己的实验结果决定剧情。第二关计划从手动决定何时起跳，走到模仿教练，再到从奖惩中学习。第三关会把学到的策略带进连续决赛和栈道巡检。[三关故事线](剧情课程故事线.md)

## 哪次重复有学习价值

同一条弯道值得跑两次。把胸口姿态传感器设为“仅测量”，学生能读到 44.1° 的侧倾，但机器人在 14.9 米失衡。保留同一套硬件，把读数接给控制器，峰值降到 7.8°，跑完 40 米。第二次只改一个条件，给了学生能用来解释第一次失衡的新证据。失败的学生也可以据此决定下一轮要改什么。[同场实验与数据](剧情课程故事线.md) · [失衡后的实测画面](story-review/failed.jpg)

## 希望得到的修改意见

请先给出一版从初代机撑地到第一次尝试跨栏的逐页顺序。每页用一句话交代学生从上一页带来了什么、现在要作哪个新决定、这一步的结果怎样引出下一页。标出哪些页面可以合并，哪些同场复测应该保留，并说明手动操控、模仿学习、强化学习的先后理由。这轮先审方案，沿用 V6 美术和真实仿真结果。

要实际体验，可克隆 `codex/v6-story-review`，在仓库根目录运行 `npm run dev`，打开 `http://127.0.0.1:4180/story.html`。Windows 也可双击仓库中的“打开剧情课堂.cmd”。
