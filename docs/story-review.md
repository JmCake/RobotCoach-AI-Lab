# 第一关连贯性审阅

《机器人进化跑》面向课堂上的学生。学生担任同一台机器人的总教练，通过真实仿真决定下一段剧情。教师试玩第一关《感知世界》后，最直接的感受是“感觉不连贯，老是回退”。下面列出可以操作复现的位置，供审阅时对照。

## 顺着主线走一次

初代机在弯道撑地 → 学生提出猜想 → 在干燥急弯跑出初代机的对照成绩 → 维修舱改装 → 同条件重跑 → 读本轮证据。失败可以改装重试，通过后会播放过弯镜头，再停在第一道矮栏前。摄像头检测到了弯道，在这条赛道上，加雷达仍跑到 14.9 米。把胸口姿态传感器的读数接给运动控制器，可以跑完 40 米。[三关故事线和同场试跑数据](剧情课程故事线.md)

## 哪些操作让人觉得倒退

| 复现操作 | 屏幕和进度发生什么变化 | 审阅时可以追问什么 |
| --- | --- | --- |
| 只加雷达，失衡后点「调整配置再试」 | 两次试跑的成绩都在记录里。画面从赛后定格切回维修舱，进度从「赛后复盘」退到「同场试跑」。 | 学生在哪儿能看出，下一次改装正在检验上一轮的新发现？ |
| 在维修舱点「回看我的猜想」，再点「带着猜想去维修舱」 | 前一次试跑成绩保留。两次点击先回到完整的提问画面，再回到同一间维修舱。 | 只想核对一句猜想，是否需要离开当前场景？ |
| 正在试跑时刷新 | 这次在 2.1 米刷新，回到同一试跑画面，距离变为 0.0 米，需要再起跑。猜想和已经完成的成绩仍在。 | 当前这一趟的进度确实丢了。中断后应如何恢复或说明？ |
| 通过急弯，看完矮栏定格，点「查看后续课程地图」 | 机器人已面对新障碍，进度仍标着「赛后复盘」。主按钮打开地图，再点「手动操控」进入原版课堂。第二关目前有原实验入口和剧情设计。 | 跨过这一关时，怎样让学生带着“什么时候起跳”的问题继续？ |

下面三张是同一浏览器会话中的连续操作。失败后返回维修舱保留雷达，之后卸下雷达并给 IMU 接入控制器，过关才出现矮栏。[失衡后看成绩](story-review/failed.jpg) → [点重试后回到维修舱](story-review/retry.jpg) → [通过后停在下一道栏前](story-review/hurdle.jpg)

## 打开与定位

克隆 `codex/v6-story-review` 后在仓库根目录运行 `npm run dev`，打开 `http://127.0.0.1:4180/story.html`。Windows 也可双击启动器。入口页面、交互流程、共享急弯实验和浏览器用例分别见 [story.html](../story.html)、[story.js](../assets/story/story.js)、[curve-trial.js](../assets/motion/curve-trial.js) 和[第一关回归测试](../tests/e2e/story-class.spec.js)。

本轮请先给出一条从撑地到矮栏的课堂主线，注明哪些重试能帮助学生检验猜想、哪些往返可以合并，以及每次调整后学生能看见什么新证据。建议应沿用 V6 美术、实际仿真成绩和失败重试机制。
