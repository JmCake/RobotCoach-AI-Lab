# 导演脚本归档

据项目方提供的定稿归档，保留故事及课堂对白。外部视觉参考链接与图片仅在本地交接件内查阅。

我想把这次的故事设计得更有情节一些，而不是单纯串联几个知识点。

整部作品始终围绕同一台机器人展开。它最初的愿望很简单——完成一场比赛。但随着学生不断帮助它成长，它逐渐发现，自己学会的这些能力还有更重要的用途。

学生也会经历一个身份变化：从帮助机器人解决困难的教练，到培养人工智能的训练者，最后成为思考科技如何服务人类的设计者。

# **《机器人总教练：奔跑的意义》**



## **序幕 · 一台机器人的梦想**

体育场内人声鼎沸，观众席上响起阵阵欢呼。

镜头掠过红色跑道、计时器、起跑线，最终停在一台蓝白色机器人身上。

它活动了一下机械手臂，蓝色的眼睛逐渐亮起。

**机器人：**

「听说今天这里要举行机器人运动会，我也想参加！不过，我还缺少一些经验……你们愿意做我的总教练吗？」

镜头转向前方的赛道。

发令枪响起，机器人冲出起跑线。

整段开场采用全屏动画，不需要任何操作，迅速把学生带入故事。

# **第一关：拯救初代机器人**



### **第一幕：意外发生**

机器人自信地奔跑着。

镜头切换到它的第一人称视角，前方的白色跑道线逐渐弯曲。摄像头已经发现弯道，机器人也开始调整方向。

然而，它的身体越来越倾斜。

它试图挥动双臂维持平衡，却最终失去控制，单手撑地，停在了跑道上。

观众的欢呼声戛然而止。

画面定格。

屏幕出现一个问题：

**它明明看见了弯道，为什么还是摔倒了？**

课堂提问效果示意

它没有看清前方的道路

它不知道自己的身体正在倾斜

它没有及时感知脚底的情况

老师组织学生讨论，随后在同一个画面上揭示摄像头、身体姿态和脚底的相关线索。

不需要单独的调查页面，也不需要学生填写调查报告。

### **第二幕：给机器人增加新的能力**



机器人来到维修舱。

**机器人：**「教练，我已经能够看见道路了。是不是还需要其他能力？」

画面出现四种装备。


**摄像头**

观察环境


**激光雷达**

测量距离


**IMU**

感知姿态


**足底力觉**

感知接触

老师邀请同学选择需要增加的传感器。

这里直接接入我们已经开发好的传感器安装与试跑实验。

学生可以尝试不同方案。如果机器人仍然失败，就根据本次结果调整装备；如果成功，就展示真实成绩。

尤其可以让学生发现，即使安装了姿态传感器，也需要将测量结果交给控制器，才能真正帮助机器人调整身体。

### **第三幕：新的挑战出现了**



机器人终于能够稳定通过弯道。

**机器人：**「原来如此！不仅要看见前面的路，还要知道自己的身体发生了什么变化。」

观众再次欢呼。

但就在大家以为问题已经解决的时候，镜头继续向前移动。

一架矮栏出现在跑道中央。

机器人发现障碍物，画面定格。

**机器人：**「教练，我看见障碍物了。可是，我应该现在跳，还是再跑几步？」

随后，它又问了一句：

**「难道以后每遇到一个障碍，我都要等你们告诉我该怎么做吗？」**

这句话直接引出第二关。

第一关实际上只有一次主要课堂讨论、一次改装实验，其余情节通过动画完成。

# **第二关：我是机器人总教练**



### **第四幕：机器人怎样才能自己学会？**

机器人站在跨栏前，望着远处连续排列的障碍。

老师提出新的问题：

**我们不可能永远跟在机器人身边指挥它，怎样才能让它自己学会做出选择？**

此时画面像漫画书一样分成左右两格，出现两种训练方式。


**跟着教练学**

观察别人什么时候跳，什么时候蹲，再尝试模仿。


**自己试错学**

不断尝试，根据成功和失败的结果调整自己的行为。

**教师：**「这两种学习方式有什么不同？如果你是总教练，你会怎样训练它？」

通过这个问题，自然引出模仿学习与强化学习。

不再安排学生专门玩一次手动跨栏游戏，也不再分别打开两个知识讲解页面。

### **第五幕：机器人训练营**

这一幕可以设计得非常有趣，采用训练蒙太奇与真实实验相结合的方式。


**训练方式一：模仿学习**

教练示范动作，机器人观察当时的环境与对应动作，随后独立进行挑战。

调用已有的模仿学习实验，观察实际效果。


**训练方式二：强化学习**

机器人开始独立探索。没有人直接告诉它正确动作，只有成功或失败带来的反馈。


# **−12**

碰撞失败


# **+8**

成功越障


# **继续学习**

积累经验

这里接入已经开发好的真实 Q-learning 训练过程。

可以把训练时间加速，让学生在短时间内看到机器人反复尝试、调整策略的过程。

不必展示大量复杂的 Q 表数值，只需要让学生理解奖励从哪里来、策略为什么发生改变。

训练前后的测试结果直接呈现在画面中，无须再进入独立的成果展示页面。

**机器人：**「教练，这次没有人告诉我什么时候跳。我也开始能够自己做出选择了！」

此时，体育场广播突然响起：

「各位参赛选手请注意，机器人综合挑战赛即将开始！」

体育场大屏幕亮起，六段不同环境的赛道依次出现。

# **第三关：面对未知世界**



### **第六幕：最后的比赛**

这一次，不再是单独练习过弯或跨栏，而是一场综合考验。


直道


障碍


弱光


急弯


凹凸


湿滑

赛前，老师让同学们为机器人确定最终装备和学习策略。

**教师：**「前面我们已经帮助它解决了很多问题。这一次，它需要连续面对六种不同的环境。大家觉得，它准备好了吗？」

倒计时开始。

3、2、1——

直接启动现有的六段连续总决赛。

比赛过程中，画面自然展示机器人的感知、决策、行动和反馈，不再单独安排闭环组装课程。

实际比赛结果决定后续画面。成功可以庆祝，失败也可以复盘，不预设机器人一定夺冠。

比赛结束后，机器人站在终点附近。

它抬起头，看着体育场外的世界。

### **第七幕：没有跑道的地方**



镜头从红色跑道逐渐过渡到山间木栈道。

观众的欢呼变成了鸟鸣和流水声。

机器人停下脚步。

**机器人：**「这里没有白色跑道线，也没有提前布置好的障碍物。我该怎么知道哪里可以走呢？」

漫画画面逐渐切换成真实的九寨沟照片。


老师请同学们先判断：

**如果机器人要继续前进，你会让它把下一步落在哪里？**

随后运行已有的真实 AI 图像识别实验。

学生可以观察 AI 如何识别路面、水面、障碍物，也可以找出它判断错误的地方。

这一幕的意义不是证明机器人已经能够在真实世界自由行走，而是让学生看到：人工智能确实能够处理真实环境的信息，但仍然需要人类验证和指导。

**机器人：**「原来，真正的世界比比赛场地复杂得多。」

短暂的停顿。

「可是，教练，我们学习这些能力，难道只是为了参加比赛吗？」

这是整部作品最重要的转折点。

到这里，所有教学互动结束。

# **终章：奔跑的意义**

接下来是一段完整的电影式动画，不再进行课堂答题，不再出现实验按钮，不再打断故事。

## **第八幕：奔赴救援现场**



画面渐暗。

新闻播报声响起。

「某地发生地震，部分道路和建筑受损，救援人员正在开展紧急搜救工作。」

镜头中，救援人员面对复杂的废墟环境，一些区域尚未确认是否安全。

同一台蓝白机器人出现在救援队伍中。

它不再佩戴运动会的号码牌，而是增加了救援通信设备。

救援人员向它交代探查任务。

**机器人：**「收到。这一次，我会小心前进。」

随后进入一段连续动画。


**黑暗中的眼睛**

机器人利用感知设备观察光线不足的环境。

短暂闪回第一关，它第一次学会观察世界。


**废墟中的脚步**

机器人谨慎地调整姿态，尝试通过复杂地面。

短暂闪回它曾经在跑道上失衡、撑地的画面。


**面对未知的选择**

机器人发现前方存在障碍，评估环境，遇到无法判断的风险时停下并等待救援人员指令。

短暂闪回跨栏训练和自主学习的经历。


**让危险离人类更远**

机器人将现场信息传回指挥人员，辅助他们确定后续救援方案。

这里不需要旁白逐个解释传感器和算法。

前面所有的课堂知识，都通过机器人在救援场景中的行动得到呼应。

## **第九幕：科技的温度**



机器人完成探查任务，走回救援队伍。

一名救援人员向它伸出手。

镜头特写两只手握在一起的画面。

此时闪回故事开始的那一刻——机器人摔倒在跑道上，伸出机械手臂，等待教练的帮助。

曾经，是人类帮助机器人。

如今，机器人也能够帮助人类。

旁白缓缓响起：

> 曾经，它连一个弯道都无法顺利通过。
>
> 我们教会它感知世界，稳住身体，学会选择。
>
> 而未来，这些能力可以让机器人走进人类难以抵达的地方，承担危险的任务，帮助守护生命。

镜头逐渐拉远，阳光照亮救援现场。



# **我们教会机器人奔跑，**

# **不是为了让它赢过人类，**

# **而是为了让科技抵达危险，让生命远离危险。**

**科技向善 · 智能为人**

字幕淡出，影片结束。

# **整堂课实际上有多少操作？**

虽然故事画面丰富，但教师和学生真正需要参与的地方很少。

| 剧情   | 课堂参与         |
| ---- | ------------ |
| 序幕   | 观看动画         |
| 第一关  | 讨论摔倒原因、改装试跑  |
| 第二关  | 讨论学习方式、观察训练  |
| 第三关  | 配置总决赛、判断真实路面 |
| 救援终章 | 观看完整动画       |

假设是一堂 40 分钟的课，可以这样分配时间：

序幕

2 分钟

第一关

10 分钟

第二关

12 分钟

第三关

13 分钟

救援终章

3 分钟

# **整部作品的核心设计**

我希望我们牢牢抓住三条同时发展的主线。

| 发展阶段 | 机器人成长      | 学生成长         |
| ---- | ---------- | ------------ |
| 第一关  | 从失衡到稳定     | 学会观察、分析与解决问题 |
| 第二关  | 从接受指令到自主学习 | 理解人工智能的学习方式  |
| 第三关  | 从训练场走向未知环境 | 认识人工智能的能力与局限 |
| 终章   | 从参加比赛到协助人类 | 理解发展科技的社会意义  |

这一版没有必要再继续增加关卡、知识点和实验了。我们需要把精力集中在故事、美术、动画和转场的质量上。

上面的图片是视觉参考，并非统一制作完成的原创分镜。正式制作应继承现有 V6 角色和动画素材，新增救援篇章明确作为未来应用设想，不虚构现有项目的实体救援能力。

**我最喜欢的设计是这部作品直到最后才揭晓真正的主题：学生以为自己在培养一位运动员，实际上是在培养一台未来能够帮助人类的机器人。**
