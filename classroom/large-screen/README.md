# 机器人总教练 · 大屏精简版

双击仓库根目录的 [机器人总教练-大屏精简版.html](../../机器人总教练-大屏精简版.html) 即可离线授课。方向键切换环节，顶部关卡可以跳转。实验详情和暂停由教师控制。

巡检时点击 A、B、C 或可通行地面移动，按 T 切换普通视觉与热成像。热源表面在探测范围内持续接受扫描后才会标记。避障、火焰、热成像和位置回传在浏览器本地模拟。完成三处标记后可发回报告，进入单图结尾。

运行 `python classroom/large-screen/build.py` 可从源码重建单文件。课堂页面、样式和固定步长运动模型从本次提供的大屏精简版拆出；`bend.js` 和 `rescue.js` 分别绘制弯道和巡检。图像出处见 `media.json`。同目录的动作切片及识别图层沿用提交的课堂文件。摄影视图来自 rheins 的九寨沟照片（CC BY 3.0），详见[第三方声明](../../THIRD_PARTY_NOTICES.md)。单文件中的落脚点比对使用保存的模型输出，仓库另保留[本地推理实验](../../experiments/road-vision.html)。

结尾的语音由本机中文语音合成。字幕与音轨使用同一句话。声音关闭时可单独点「重听配音」。
