# RobotCoach-AI-Lab

**项目状态：V1.0 已实现并完成本地验收，等待 PR 审查；尚未合并或正式发布。**

本项目基于原作者 [PumpkinKiller04/RobotCoachAI](https://github.com/PumpkinKiller04/RobotCoachAI) 的课程与交互设计进行精简改造，目标是将《机器人总教练请就位》从复杂的导学单网站，改造成**打开即可体验、单页顺序推进、以机器人互动为核心**的教学网站。

> **开发基线**：[完整实施计划与三个版本路线图](DEVELOPMENT_PLAN.md)。本实现从新仓库的方案基线开始，选择性复用原作者静态代码；不包含废弃的 Vue/TypeScript 仿真系统。

## 打开网站

需要 Node.js 18 或以上版本。生产页面没有第三方运行依赖，也没有后台服务。

```bash
git clone https://github.com/JmCake/RobotCoach-AI-Lab.git
cd RobotCoach-AI-Lab
git switch codex/v1-foundation
npm run dev
```

访问 **http://127.0.0.1:4180**，直接进入第一章。也可以在项目目录运行 `python -m http.server 4180`，再访问相同地址。请通过 HTTP 打开，不直接双击 HTML（浏览器对本地 ES 模块有限制）。手机访问时，可使用静态托管站点，或将 Python 服务的局域网地址用于同网设备。

## V1.0 已实现

11 页连续课程：初代机诊断 → 四种感官 → 点击/拖拽安装 → 配置试跑对照 → 行为克隆原理演示 → 键盘/触屏操控 → Q-learning 训练 → 冻结策略展示 → 闭环拼装连线 → 节点故障与视频 → 五项图形化方案与总结。

保留倒立城市、书本色彩、红色操场、开场自动跑酷、原版机器人与深色实验窗口。页面切换约 200ms，支持减少动态效果偏好；手机可用点选完成拖拽任务。本地保存阅读位置、感官配置、已完成试跑、人工最高分、Q 表、训练记录、闭环配置与最终方案。离页销毁实验，隐藏页面暂停活动循环。

没有账号、姓名密码、选课、作业提交、云数据库、打分、报告、勋章、广场、图片问答、聊天或远端字体。生产网站只请求自身静态文件。

## 学习算法与演示边界

- 第一章试跑沿用原版的**教学机制演示**，不宣称真实传感器仿真或物理验证；页面明确标注。
- 行为克隆页通过“示范与环境变化”说明模仿局限，使用标明性质的动作回放，**没有独立行为克隆训练模型**。
- Q-learning 从空 Q 表开始，根据距离、障碍类别、跳跃状态和速度选择等待、跳跃或下蹲。实际执行 `Q ← Q + α[r + γ max Q′ − Q]`，终止时不自举；没有预置成功策略或专家数据。碰撞、跨障碍和奖励均来自同一跑酷引擎。
- 成果页冻结 Q 表、关闭探索，展示实际策略。训练不保证每轮成功；记录保留最近 150 轮，清空浏览器数据会丢失本地进度。

## 开发与测试

```bash
npm ci
npx playwright install chromium
npm test
npm run test:e2e
npm run build
```

`npm test` 为算法检查；Playwright 为真实 Chromium 交互测试，包含桌面、手机视口和触屏模拟；`dist/` 是可部署到任意静态服务器的完整产物。`node scripts/evaluate-learning.mjs` 可复现三组实际训练数据；`node scripts/generate-videos.mjs` 可重新生成四段自有图形演示视频。已有本机 Chromium 时，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定其路径。

本地验收：5 项算法测试、14 项浏览器测试通过，另检查构建产物。浏览器实录的早期训练仍有碰撞；100,000 次更新后的三组冻结测试平均跨障碍数为 18、18、15.55（训练前为 0）。这不是 V1.1 的训练优化或 V2.0 泛化验证。

## 产品目标

保留原作者的三章教学逻辑与核心交互：**感知 → 学习 → 闭环**。

- **第一章｜感知与选拔**：初代机器人诊断、认识感官、安装传感器、升级试跑与结果对比。
- **第二章｜学习与训练**：行为克隆原理、人工控制、Q-learning 自主试错、奖励反馈、训练成果展示。
- **第三章｜决策与闭环**：闭环拼装、关闭节点观察故障、综合场景设计与课程总结。

网站以一页一页的方式推进，每页只围绕一个主要任务，形成 **简短讲解 → 直接操作 → 观察反馈 → 下一页** 的流程。顶部仅保留简洁章节导航；页面切换使用轻量淡入/位移动画，**不做左右双页，也不做复杂翻书特效**。

## 保留与删除

| 保留 | 删除 |
| --- | --- |
| 倒立城市、原版书本配色与视觉氛围 | 登录、注册、账号验证 |
| 首页机器人跑酷动画、交互实验视觉 | 独立选课页、多层环节菜单、左右双页布局 |
| 内嵌实验窗口、传感器工坊及试跑 | 传统选择题/填空题/打分/提交 |
| 人工操控、行为克隆讲解、Q-learning 训练与展示 | AI学习报告、勋章成长体系 |
| 闭环拖拽、节点故障实验及必要的视频 | 多模态图片问答、前沿案例轮播、AI创意广场 |
| 按需使用的浏览器本地进度和训练存储 | QuickForm 用户及作业数据库依赖 |

把原本的答题步骤改成**选择实际改进方向、运行实验、查看真实结果**；保留必要的简短总结，但不额外增加作业和成就墙。

## 三个开发版本

| 版本 | 目标 | 交付要求 |
| --- | --- | --- |
| **V1.0｜基础完整版** | 整合原 V1.0 + V1.1：原作者视觉和三章实验、单页顺序推进、操作反馈、讲解衔接、状态恢复、删除冗余系统 | **完整可用的网站**，不是只完成页面框架 |
| **V1.1｜训练与体验增强版** | 整合原 V1.2 + V1.3：优化 Q-learning/奖励/训练对比、机器人操作和动画、移动端、性能与稳定性 | 有可复核的训练记录和完整交互回归 |
| **V2.0｜综合升级版** | 原 V2.0：更复杂的自主控制、有效传感器融合、复杂环境与综合挑战 | 在稳定旧功能基础上实现可操作的综合任务 |

**三个版本合并了原五版计划的全部功能方向，不通过删减需求来减少版本数量。** 每个版本内部可按模块开发和测试，但不再拆成额外的对外版本。V2.0 的重大升级细节在 V1.1 验收后再确定技术实现，不预设尚未验证的效果。

## 研发边界

- V1.0 优先复用原作者的 HTML、CSS、JavaScript、Canvas 2D 与嵌入式实验，**不从此前废弃的 Vue/TypeScript 仿真项目继续开发**。
- 不引入账号、云数据库、成绩管理或与教学互动无关的功能。进度与必要的训练数据优先保存在浏览器本地。
- 训练结果必须来自真实运行和更新，**不能用预设成功动画冒充学习提升**。
- 源码、图片、视频等在复制和重新发布前核实原作者及第三方许可，保留适当署名；公开仓库不自动等于可任意复用所有素材。
- UI 保持自解释，避免控件旁堆叠说明、小字和重复提示。
